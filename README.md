# 🚗 AutoDrive — Venta y Gestión de Autos

AutoDrive es un sistema web para la **gestión y venta de vehículos**, diseñado para facilitar el control de un concesionario de autos.

El proyecto se encuentra actualmente en una primera etapa de desarrollo, funcionando de manera **local** mediante una interfaz web desarrollada con HTML, CSS y JavaScript, utilizando MySQL como base de datos administrada desde MySQL Workbench.

A futuro, el sistema será evolucionado hacia una arquitectura completa de **Frontend + Backend**, permitiendo una aplicación más segura, escalable y preparada para ser desplegada en Internet.

---

## 📌 Descripción

AutoDrive busca centralizar las principales operaciones de un concesionario de vehículos, permitiendo administrar información relacionada con:

- 🚘 Vehículos
- 👤 Clientes
- 💰 Ventas
- 📦 Inventario
- 📋 Registros de vehículos
- 🔎 Búsqueda y filtrado
- 📊 Control de información
- ⚙️ Gestión del sistema

La aplicación está pensada para que la administración de los vehículos y las ventas sea sencilla y organizada.
